# Text Studio 时间点与售后赔付检测

点击“风险检测”扫描全部话术单元的最终稿（当前候选或人工修改稿），不扫描未选候选。沿用现有风险抽屉、级别筛选、忽略和项目保存格式。

- **时间点 / 倒计时（中风险）**：识别“现在是晚上8点”“今天是9月13日”“还有10分钟结束”，兼容中文数字、时分、年月日及结束/下播等倒计时。提示循环播放可能与真实时间不符。普通“现在大家看看这个产品”、价格、产品时长和生产日期不因这些词单独命中。
- **售后赔付承诺（高风险）**：识别“坏果包赔”“不满意就赔”“假一赔十”“无条件赔”等强承诺。单纯提及赔付流程或申请条件为低风险提示；“不包赔”“不承诺无条件赔”等明确否定不作为赔付承诺。“有问题联系客服处理售后”不命中。
- 既有物流、运费险、无理由/退款、绝对化、夸大及效果检测继续保留。强赔付承诺不会因为同句附带“以页面为准”就自动降级。

点击结果中的“定位修改”会展开对应段落、聚焦编辑框并选中命中短语。输入修改后自动保存，同时清空过期检测结果；再次点击“风险检测”检查新稿。规则给出提示与修改建议，不自动改写原文。规则属于显式语言模式匹配，不能穷尽转述、隐喻或所有否定句式。

实现职责：`web/text-studio-risk.js` 维护规则及纯文本扫描；`web/text-studio.html` 负责最终稿选择、结果展示、定位和保存；`server/text_studio.py` 提供固定脚本资源路径。正式入口 `server/text_studio_entry.py` 沿用该路径，商品事实一致性检测仍独立运行。

更新后需正常重启 Text Studio 服务以加载新增脚本路由，再刷新页面。启动入口仍为 `bash scripts/text-studio-start.sh`。

验证：

```bash
node tests/test_text_studio_risk.js
python3 -m unittest discover -s tests -p test_text_studio.py
python3 -m unittest discover -s tests -p test_service_entrypoints.py
```

`tests/text_studio_risk_browser_checks.js` 是浏览器端验收脚本：在指向独立临时项目目录的全新 Text Studio 页面执行，使用实际保存/读取 API，不调用模型或 TTS。覆盖两类检测、误报、级别筛选、仅扫描选中最终稿、结果保存、定位选词、编辑自动保存、重新载入和复检。验收临时项目保留，不自动删除。
