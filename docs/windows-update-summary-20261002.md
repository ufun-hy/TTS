## 已完成修改

| 范围 | 行为与原因 |
| --- | --- |
| 录音转写 | 上传、解码、模型加载、分段识别分别显示进度；任务和检查点持久化，支持暂停、继续、重启恢复；删除移入回收区，保留原录音。 |
| 进程和资源管理 | 识别 Windows PID 复用，避免终止无关进程；ASR 子进程监控父进程退出；多页面分别维持会话，关闭全部页面后停止 Runtime，释放模型资源。 |
| NVIDIA 显卡选择 | 每次引擎冷启动过滤并验证唯一 NVIDIA Vulkan 独显，避免固定 Vulkan 编号变化后误用 Intel 集显；无法确认设备时明确失败。 |
| Ollama 文本泛化 | 使用 JSON Schema 约束段落 ID 和候选数量；拒绝残缺 JSON，输出达到长度限制时提供明确错误。 |
| 录音创建音色 | 音色选择框旁新增「添加音色」，支持 3～30 秒录音、中文名称、用户核对原文、生成后自动选中和试听；备份配置并保留录音产物。 |
| 音色热加载 | Gateway 向界面传递动态显示名；配置版本同时检查时间、大小和文件标识，修复 Windows 快速原子替换未刷新列表的问题。 |
| 压测工具 | 增加长短混合文本、逐次冷启动、预热排除、分组统计、加权 RTF 和采样记录；不把缓存命中算作推理吞吐。 |
| 构建与回归 | 完整包检查 CosyVoice CLI；完整包及补丁 CI 纳入新增功能测试。更新解码阶段旧断言，并避免日志测试误匹配合法耗时。 |
